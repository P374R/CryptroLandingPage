# The Future of Cryptocurrency

A modern responsive landing page showcasing how cryptocurrency works, featuring an interactive blockchain transaction infographic.

##  Features
- **Crypto Infographic Section:** A step-by-step visual breakdown of how a Bitcoin transaction is entered, transmitted, verified by a peer-to-peer network, clustered into blocks, chained permanently, and completed.
- **Modern UI:** Dark-themed futuristic background network animation.
- **Contact & Support:** Built-in section for user inquiries and assistance regarding tech support.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Futuristic and Responsive Dark Theme)
